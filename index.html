FuzzyGraph

            

                Equation
                Fuzzy function
                Colors
                Advanced
                Shortcuts
            

            

                

                    
A fuzzy (non-binary) graphing calculator. A normal graph draws only the points where both sides of the equation are exactly equal. FuzzyGraph colors every point by how close the two sides are, so you see the whole error landscape: graphs of approximate equations (≈).

                    
Free and open source. Project by math artist Caleb Madrigal.

                


                

                    
Equation

                    
Needs one = and uses x and y, e.g. y = x^2. Polar equations use r (distance from the origin) and t (angle, 0 to 2π), e.g. r = sin(3*t). Complex numbers work with i; the two sides are compared by their real parts.

                    
Functions inserts functions and opens the Cymatics, Mandelbrot and Julia generators. Editor opens a larger editing window.

                    
Drag left/right or scroll over any number in the equation to change it.

                    
View examples

                


                

                    
Fuzzy function

                    
Turns the error at each point into a color position. v is the error (0 = exactly true) and f is a parameter you set with the slider (0.01 to 1). The default is (v + 0.000001)^f: a small f spreads the colors over the low errors near the graph, a large one keeps the error closer to linear. Pick a preset or write your own with the same functions as equations, e.g. log(v + 0.01).

                    
At f = 0 the function is not used and the graph is drawn as plain lines.

                


                

                    
Colors

                    
The equation defines the data; the color map defines which colors show which values. The bar next to the color map name is the current mapping, smallest error on the left.

                    
Reverse flips the color map end to end. Invert inverts the colors themselves (like a photo negative).

                    
The same data can be shown in many ways. There is no one right representation.

                


                

                    
Advanced

                    
Value range: colors are spread between the smallest and largest error in view. Errors are absolute values, so the minimum is usually 0. A small area of very large error can wash out everything else, like the sun in a photo; setting a lower max brings back the detail. Empty means automatic.

                    
Color start and color cycles shift and repeat the color map. Hue, saturation and lightness adjust its colors. While Advanced is closed, the value range resets whenever the view or the equation changes.
